# Figma design-system build progress + API gotchas

> BRIC DS component build state and Figma-authoring lessons learned. Mostly relevant only if picking Figma design-system work back up — the button state model / color spec summarized here is the source of truth that bric-framer-translation.md and visual-language-direction.md reference.

## Component build state (Figma, Jun 18 2026)

Seven component groups built and audited in Figma: Checkbox, Segment Toggle, Range Slider, Status Chip, Toast, Panel Chrome, Divider. Each exists as both a dark-mode and (for most) a separate light-mode component set — **dark and light versions are separate component sets in this file, not mode-variants of the same instance**, which matters because a token-value change hits both automatically but a structural edit (geometry, rebinds, layer order) has to be applied to both sets by hand. This bit the build once (corner/scanline edits only landed on the dark sets initially).

## Canonical button spec (current, locked Jun 18)

Fixed-size 128×32 (was 128×48 — revised because at 48px a button edge always lands mid-stud-row on the background grid; at 32px it lands on cell boundaries). Pixel-stepped corners generated by a size-independent algorithm that snaps the offset from each corner vertex, not a global grid — meaning corners stay symmetric at any width/height, which is the version that should be ported to CSS (see bric-framer-translation.md).

**State model** (Battlefront-2-inspired, replaced an earlier Emphasis×State model): axes are Register (Available=amber / Coming-soon=teal) × Selected (no/yes) × Current (no/yes) = 8 variants. No fill = selectable; holo glow = active/current; solid fill = selected; solid+glow = selected+current (layered). Holo is the active/current highlight colored per register — not a "disabled" indicator, which is now carried by the teal register color instead.

**Color spec:** Holo register (emitted light, not flat) — body `#78E0D6`@26%, inner edge `#AAF5EE`@80%, outer glow `#5ABFB8`@45%/16px blur, scanlines `#96EBE2`@12% at 3px pitch, hot label `#EAFEFB`. Alloy/built register — flat matte amber `#E9A73E`, label `#1A0F02`, same pixel-step corners, no glow/scanlines.

**Ambient motion (locked):** flicker + scanline drift + chromatic edge, constant while idle; a reconstruction sweep plays on entrance only; no glitch/tear effect on CTAs ever. All of this must be fully disabled under reduced-motion, not just slowed.

## Figma API lessons (only relevant if scripting Figma via the Console MCP again)

- `figma.combineAsVariants()` on an EXISTING component set's children destroys the set — it moves the variants out and builds a new set; removing the "old" set afterward deletes them permanently. To add a variant to an existing set, use `existingSet.appendChild()` and position manually instead.
- A bound variable's paint can silently render as a flat grey placeholder on some nodes (notably ones that also carry an effect style) even though the API reports the correct resolved value. Fix: bake the variable's *resolved* color as the paint's base color when binding, so a fallback is visually indistinguishable from the correct value.
- `figma.createVector()` normalizes geometry to its bounding-box origin — a grid built with elements centered at e.g. x=8,40,72 will silently re-render shifted to x=0,32,64. Offset the whole node by half the grid gap after creation if center-alignment matters.
- Prefer `figma_capture_screenshot` (live plugin runtime) over `figma_take_screenshot`, which can return a stale cached image.
